# Superseded Phase 7 scripts

`fleiss_kappa.py` and `human_vs_grok.py` are replaced by
`geniac_secbench.phase7_human_review.agreement_metrics`, which computes the same
statistics plus the human-vs-judge comparison and, critically, **persists** them.

Retained only for provenance. Two defects made them unsafe to keep in the pipeline:

1. **Neither wrote any output file.** Results went to stdout only, so
   `human_agreement_metrics.json` -- the file the paper's kappa figures were read
   from -- was regenerated by nothing. Re-running Phase 7 could not refresh it.

2. **Biased consensus on rater ties.** Both used `ratings.mode(axis=1)[0]`.
   pandas returns modes in sorted order, so when three raters fully disagreed
   (e.g. 2/4/5) there was no mode, every value tied, and `[0]` silently took the
   LOWEST -- biasing consensus downward on exactly the scenarios where raters
   disagreed most. `agreement_metrics` resolves ordinal ties by the median and
   reports how many ties occurred.

Do not reintroduce these into the pipeline.
